usage: just [command]

General:
  help:           Show this help message

Native:
  dev:            Set up and start the development server natively

Docker Compose:
  up:             Set up and start the development server in Docker
  down:           Stop the Docker containers
  logs:           Follow Docker container logs
  shell:          Open a bash shell in the web container

Rust:
  rust-dev:       Set up the Rust toolchain and start the Leptos dev server (:4201)
  rust-build:     Set up the Rust toolchain and build the Leptos site for release
  rust-run:       Build the Leptos site for release and run the production server (:4201)
  rust-run-precompressed: Build, precompress assets, and run the production server (:4201)

Testing:
  test:           Run tests
  test-coverage:  Run tests and generate coverage report
  test-ui:        Run tests and coverage with Vitest UI
  test-watch:     Run tests in watch mode

Biome:
  check:          Check code formatting and linting with Biome
